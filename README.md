# الخزنة العنيدة — القفل الأول: المزلاج الكتوم

لعبة ألغاز داكنة وصامتة: مزلاج ميكانيكي في مسار معدني، عليك أن توصله إلى العلامة ببطء، ثم تثبت داخلها حتى يكتمل التعشيق. الخزنة لن تكتفي بالمشاهدة؛ ستُطلق إشعاراً منسجماً مع طابعها، وتُزحزح العلامة زحزحةً محسوبة، وتدفع المزلاج دفعاً خفيفاً في اللحظة الحرجة. من يندفع يرتدّ مزلاجه، ومن يثبت يُفتح له — على مضض.

هذا المستودع يحتوي **القفل الأول فقط**، مبنيّاً بلا أي اعتماديات خارجية (HTML + CSS + JavaScript وحدات ES)، وبمنطق منفصل تماماً عن العرض واللمس.

---

## التشغيل

```bash
npm run dev      # خادم محلي على http://0.0.0.0:4173
npm test         # اختبارات منطق القفل (node:test، بلا اعتماديات)
```

> الوحدات (ES Modules) تحتاج خادماً؛ فتح `index.html` مباشرةً من القرص لن يعمل في المتصفحات الحديثة.

المتغيّرات الاختيارية: `PORT` و`HOST`.

## البنية

| الملف | المسؤولية |
| --- | --- |
| `index.html` | الهيكل والوسم الساكن (SVG للمزلاج، لوحة الإشعار، شاشة الاكتمال) |
| `src/config.js` | **كل** الأرقام القابلة للمعايرة و**كل** النصوص العربية |
| `src/latch-lock.js` | آلة الحالة + محاكاة النابض + كتم الاندفاع (خالٍ من DOM) |
| `src/render.js` | ترجمة لقطة الحالة إلى SVG وواجهة، ولا يعرف شيئاً عن الفيزياء |
| `src/app.js` | اللمس/الفأرة/لوحة المفاتيح، الحلقة الزمنية، وربط الأحداث بالإشعارات |
| `src/sound.js` | أصوات ميكانيكية قصيرة مولّدة بـ WebAudio (بلا ملفات صوت) |
| `src/style.css` | الهوية الداكنة، الحركة البطيئة، وإخفاء كل ما ليس العنصر النشط |
| `tests/latch-lock.test.mjs` | اختبارات سلوكية للمنطق (12 اختباراً) |

**فصل المسؤوليات:** `latch-lock.js` لا يرى شاشة ولا مؤشراً؛ يستقبل أوامر (التقاط/تحريك/إفلات/خطوة زمنية) ويُخرج لقطة حالة + أحداثاً (`grab`، `holdStart`، `recoil`، `provoke`، `fail`، `unlock`). لذا يمكن ضبط الصعوبة كاملةً من `config.js` دون لمس المنطق أو العرض.

## دورة اللعب (آلة الحالة)

| الحالة | متى تحدث | ما يراها اللاعب |
| --- | --- | --- |
| `idle` | البداية، وبعد كل فشل | المزلاج عند نقطة السكون، والهدف مضاء بهدوء |
| `dragging` | بعد التقاط المزلاج وتحريكه | المزلاج يتبع الإصبع بنابض ناعم، وشرطات المسار تشير إلى تقدّمه |
| `holding` | دخول المزلاج نطاق الهدف (12% من المسار) | حلقة رفيعة تُرسم ببطء على مدى **2.7 ثانية**، وهدف يتنفّس بهدوء |
| `open` | امتلاء العدّاد كاملاً | المزلاج ينزلق إلى عمق القفل، وشاشة «فُتح القفل الأول» |

**الفشل** يحدث في ثلاث حالات، وكلها تُفرّغ العدّاد بنعومة (0.64 ثانية) وتُعيد المزلاج إلى البداية:

1. **التسرّع:** تجاوز سرعة السحب الحدّ المسموح مدةً كافية → ارتداد ميكانيكي + إشعار تنبيه.
2. **مغادرة الهدف** أثناء الثبات.
3. **إفلات المزلاج** داخل الهدف قبل اكتمال العدّاد.

**الاستفزاز:** عند 42% من العدّاد تُزيح الخزنة علامة الهدف قليلاً وتدفع المزلاج دفعةً خفيفة وتُظهر الإشعار الأول؛ وعند 78% تُكرّر الفعلة صامتة. بعد كل استفزاز مهلة سماح (0.7 ثانية) لا يُحتسب فيها الخروج فشلاً، حتى يكون الاختبار في **ردّ فعلك** لا في صدفة المكان.

**تكرار الخطأ:** بعد ثلاثة إخفاقات يظهر تعليق السخرية، ثم يتكرر كل ثلاثة إخفاقات.

## المعايرة (`src/config.js`)

| المفتاح | القيمة الحالية | المعنى |
| --- | --- | --- |
| `track.start` | `0.82` | موضع سكون المزلاج (نسبة من المسار) |
| `track.targetCenter` | `0.28` | مركز علامة الهدف |
| `track.targetHalfWidth` | `0.06` | نصف عرض نطاق الثبات (النطاق الكامل 12%) |
| `spring.stiffness` / `damping` | `165` / `26.5` | صلابة متابعة المزلاج وتخميده (بلا تجاوز) |
| `input.grabTolerance` | `0.085` | أقصى بُعد بين الإصبع والمزلاج ليُلتقط |
| `speed.maxTrackPerSecond` | `0.55` | أقصى سرعة سحب مسموحة (مسار/ثانية) |
| `speed.strainRate` | `5` | سرعة تراكم الإجهاد عند تجاوز الحد |
| `speed.recoilImpulse` | `1.15` | قوة الارتداد الميكانيكي |
| `speed.inputLockMs` | `300` | تجاهل الإصبع بعد الارتداد حتى لا يقفز المزلاج |
| `hold.durationMs` | `2700` | مدة الثبات المطلوبة |
| `hold.drainMs` | `640` | زمن تفريغ العدّاد |
| `hold.graceMs` | `700` | مهلة السماح بعد كل استفزاز |
| `hold.provocations` | عند `0.42` و`0.78` | مواضع الاستفزاز ومقدار إزاحة العلامة ودفع المزلاج |
| `fail.sarcasmAfter` / `sarcasmEvery` | `3` / `3` | متى يظهر تعليق السخرية |
| `notice.lifeMs` / `hasteCooldownMs` | `4300` / `1500` | عمر الإشعار ومهلة تكرار تنبيه التسرّع |

**لتغيير الصعوبة:** ارفع `hold.durationMs` أو خفّض `targetHalfWidth` أو `maxTrackPerSecond`؛ ثم أضف استفزازاً ثالثاً في المصفوفة إن أردت. لا حاجة لمسّ أي منطق.

## النصوص (`STRINGS` في `src/config.js`)

كل النصوص في قاموس واحد، ولا يوجد نص عربي محروق في الـ HTML أو الـ JS — العناصر تحمل `data-string` وتُملأ عند الإقلاع. لاستبدال الفصحى بلهجتك: عدّل القيم فقط.

| المفتاح | النص الحالي |
| --- | --- |
| `guidance` | أوصل المزلاج إلى العلامة واثبت حتى يكتمل القفل. |
| `haste` | الاندفاع لا يفتح الأقفال؛ تمهّل. |
| `provoke` | الآن فقط يبدأ الاختبار الحقيقي... لا تتحرك. |
| `lostStillness` | خنت الثبات في اللحظة الأخيرة. |
| `impatience` | العجلة من الخزنة... والصبر ليس من صفاتك بعد. |
| `success` | استجاب المزلاج على مضض. |

مع نصوص الواجهة الثانوية (`gameTitle`، `lockKicker`، `lockName`، `hint`، `completionTitle`، `completionSubtitle`، `nextLock`، `replay`، `soundOn`، `soundOff`، `targetLabel`) ونصوص الإتاحة (`a11y*`).

## التحكم

- **اللمس/الفأرة:** امسك المزلاج واسحبه ببطء نحو العلامة، وابقَ داخل الهدف حتى تكتمل الحلقة. لا ترفع إصبعك قبل الاكتمال.
- **لوحة المفاتيح:** `مسافة` للإمساك/الإفلات، والأسهم للتحريك (في RTL السهم الأيسر يدفع نحو الهدف). أبقِ المزلاج داخل الهدف دون ضغط الأزرار حتى يكتمل العدّاد.
- **الصوت:** زر في التذييل، والأصوات مولّدة بـ WebAudio ولا تعمل قبل أول لمسة (سياسة المتصفح).

---

## الإتاحة والتفاصيل

- الهدف معرّف كـ `role="slider"` مع `aria-valuenow` و`aria-valuetext` يتحدثان مع تقدّم الثبات، والإشعارات في منطقة `role="status" aria-live="polite"`.
- شاشة الاكتمال حوار `aria-modal` مع إدارة تركيز، وتُعطّل خلفيتها بـ `inert`.
- `prefers-reduced-motion` يوقف التنفّس والارتداد البصري ويقصّر الانتقالات، دون التأثير على المنطق.
- `touch-action: none` و`overscroll-behavior` على المنصة لمنع التمرير العشوائي أثناء السحب، واللمس يُعالج عبر Pointer Events موحّدة.
- الحركة كلها بنابض محسوب وزمن انتقالي 0.6–1s؛ لا قفزات ولا اهتزازات فوضوية.

## الخطوة التالية
